# zake-web-assets

Publika bilder för zake.se (partnerloggor och porträtt).

**Repot är publikt – lägg bara upp material som får vara offentligt.** Aldrig avtal, kod, kunddata eller interna dokument.

## Användning

Bilderna länkas via jsDelivr:

```
https://cdn.jsdelivr.net/gh/ZAKE-AB/zake-web-assets@main/partners/<filnamn>
```

## Struktur

- `partners/` – Founding Partners och samarbetspartners (`zake-fp-<namn>.svg`)
